## 자동 소개 규칙 (최종)

- 기존 질문·답변 보존 및 버전 1/2 분리는 그대로 유지한다.
- 기본 소개: 답변 작성 여부와 무관하게 매일 한국 시간 정오에 한 명.
- 추가 소개: 카드 10개에 답할 때마다 한 명. 20개면 두 명이며 하루 수령 제한은 없다.
- 사용자가 받거나 보관하거나 사용하는 소개권은 없다. 수령 버튼과 보유 수량 표시도 없다.
- 후보가 없으면 내부 달성 기록을 유지하고 이후 조회·스케줄러에서 자동 소개한다.
- 카드로 오전에 소개받은 사람은 정오의 기본 소개와 별개다.
- 이미 소개한 사람을 중복 지급하지 않도록 이정표와 실제 소개 시각을 기록한다. 기존 미수령 달성분도 자동 처리한다.
- 기존 앱의 수령 API와 응답 필드는 호환을 위해 유지하지만 새 앱은 사용하지 않는다.
- 새 DB 마이그레이션은 필요 없다. V65 및 기존 답변·소개 기록을 그대로 사용한다.
